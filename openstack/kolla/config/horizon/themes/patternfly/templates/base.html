It adds, in this order: 1. `color-scheme` meta so the browser paints native widgets correctly, 2. an inline, render-blocking script that resolves the light/dark mode from (a) cookie, (b) localStorage, (c) prefers-color-scheme, and applies `pf-v6-theme-dark` on *before* the first paint (no flash), 3. `dir` on for RTL languages, 4. the theme toggle script (deferred).
